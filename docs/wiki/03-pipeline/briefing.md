# 브리핑 생성

## 결정
`claude-sonnet-5`가 한국어로 작성. 섹션: 헤드라인 → 주목할 논문(≤5) → 업계·기술 동향(≤5) → LinkedIn 화제(≤3, 없으면 생략) → 수집 통계.

## 배경·이유
- 요약은 **자체 문장**으로, 원문은 링크로만: 저작권·신뢰성 문제 회피 (CLAUDE.md 금지 조항).
- 전문 용어 원문 병기, 모든 항목에 원문 링크: 동료가 바로 원문을 확인할 수 있게.
- 개수 상한: 아침에 짧게 읽을 수 있는 분량 유지.
- 수집 텍스트는 신뢰할 수 없는 입력이므로 프롬프트에서 태그로 격리하고, 출력은 스키마 검증 후 HTML 이스케이프.
