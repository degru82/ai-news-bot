# 중복 제거·선별

## 결정
정규화(`Item`) → 중복 제거 → 코드 사전 필터(최대 150건) → LLM 선별(`claude-haiku-4-5-20251001`, 20건 배치, 1~5점+근거).

## 배경·이유
- 같은 논문이 HF·arXiv·HN·AINews에 동시에 뜨므로 arXiv ID(버전 제거)로 병합하고 신호값을 합쳐 보여 준다. 그 외는 `utm_*` 제거 URL이 ID.
- `state/published.json`(30일)로 재등장 방지. 재발행 사고를 막는 안전장치라 정해진 로직 외 삭제·초기화 금지.
- LLM 호출 전 코드 필터(키워드·upvote·points)와 150건 상한: 비용(월 $10 이하)과 응답 시간을 예측 가능하게.
- 선별은 저비용 모델, 출력은 pydantic 스키마 검증 JSON만 허용: 모델 출력을 신뢰하지 않는다.
- 가점(신규 모델, RAG·에이전트·평가, 추론 효율, 엔터프라이즈, 규제, 금융)은 운영자 관심사 반영. 홍보·채용·근거 없는 전망·중복 보도는 감점.
